Key Features

  • One row per employee: Each employee appears only once regardless of multiple sessions
  • Timeline visualization: Multiple check-in/check-out sessions shown as segments within the same row
  • Clear time display: Check-in and check-out times clearly visible for each session
  • Total duration: Working time calculated and displayed for each employee
  • Status indication: Currently working sessions shown in green, completed sessions in purple
  • Improved readability: Easy to understand complete attendance timeline at a glance
