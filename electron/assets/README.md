# Application Icons

Place your application icons here:

- `icon.png` - PNG format icon (for Linux/Mac)
- `icon.ico` - ICO format icon (for Windows)

For now, you can use any PNG/ICO file. The icon will be displayed in:
- Application window title bar
- Taskbar
- Desktop shortcut
- Start menu

To convert a PNG to ICO, you can use online tools like:
- https://convertico.com/
- https://www.icoconverter.com/
